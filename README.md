# APP-DEVELOPMENT SMARTCENT--PART-2
SmartCent is a personal budgeting Android app prototype built with Kotlin and RoomDB. It helps users track expenses, manage categories, and visualize spending through a clean, themed UI. The project showcases applied skills in mobile development, database integration, and professional design.


## Project Overview
SmartCent is a personal budgeting Android application prototype built with Kotlin and RoomDB.  
It enables users to track expenses, manage categories, and visualize spending through a clean, themed interface.  
The project demonstrates applied skills in mobile development, database integration, and professional design.  
The primary focus is on functionality, data persistence, and a user-friendly interface.

## Functional Requirements
- Users must be able to log in with a username and password.  
- Users must be able to create categories for expense and budget entries.  
- Users must be able to create expense entries, specifying at least the date, start and end times, description, and category.  
- Users must be able to optionally add a photograph to each expense entry.  
- Users must be able to set minimum and maximum monthly spending goals.  
- Users must be able to view all expense entries created during a user-selectable period. If a photo was stored for an entry, it must be accessible from this list.  
- Users must be able to view the total amount spent on each category during a user-selectable period.  
- All data must be saved to a local SQLite database using RoomDB or a similar offline Android database platform.  

SmartCent successfully implements all of these requirements, providing a comprehensive budgeting tool that combines technical implementation with thoughtful design.

## Technology Stack
- **Language:** Kotlin  
- **IDE:** Android Studio  
- **Database:** RoomDB (SQLite)  
- **UI Design:** XML layouts with a custom theme (Navy Blue, Orange, Gold, White)  

## Project Structure
- `data/` – RoomDB entities, DAOs, and database setup  
- `ui/` – XML layouts for login, category, and expense screens  
- `activities/` – Kotlin activity files handling UI logic and database interaction  
- `themes/` – Custom app theme and color palette  

## Notes
This repository captures the iterative development process, including database setup, UI layout design, theme customization, and testing.  
SmartCent demonstrates persistence, solution-focused thinking, and attention to detail while delivering a polished prototype that embodies the principles of effective budgeting and responsible financial management.
